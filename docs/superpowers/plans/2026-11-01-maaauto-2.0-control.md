# MaaAuto 2.0 实施计划（M0–M4）

> 依据：`Desktop\Lib\MAAPJF\改造方向报告-MaaAuto2.0.md`（含 §6.4/§6.5 实测修订、§15 工程约束）。
> 目标版本 **2.0.0**。**本轮只改代码与文档，不推送、不打 tag、不发版。**

## 1. 范围

| 阶段 | 交付 | 判据 |
| --- | --- | --- |
| M0 | `upstream.py`（契约）、`run_state.py`（状态与持久化）、`orchestrator.py`（唯一状态源） | 既有 214 测试全绿；`control=click` 时行为与 1.4.6 完全一致 |
| M1 | `log_monitor.py` + `resources/log_rules.json`（内置规则表）+ 7 态判定 + 错误码 + 分类重试 | 合成日志夹具能分辨：成功 / 失败收尾 / 逐任务失败 / 未知 |
| M2 | `injector.py`（MAA 当前方案注入 + 快照/还原/补偿）、`upstream_maa.py`、`upstream_maaend.py`（`--autostart --instance --quit-after-run` + stdout） | 注入往返逐字节一致；中断后能补偿还原 |
| M3 | 更新只在轮次边界执行 + `--resume-run` 接力 + 失败后 24h 延后 | 运行中不替换文件；重启后从阶段续跑 |
| M4 | 配置精简与迁移（1.4.6 → 2.0.0）、`selfcheck.py` + 向导弹窗 | 旧配置无损迁移；空任务队列在运行前被拦下 |

## 2. 关键设计决定

1. **`control` 开关**：`inject`（默认，2.0 路径）/ `click`（1.4.6 行为，兜底）。
   `config.json` **缺这个键 = 旧配置 = 走 click**；`load_config` 的迁移会补上 `inject`。
   这样既有测试（直接构造 dict 调 `execute_workflow`）保持旧路径，真机用户走新路径。
2. **`automation.py` 保留全部公开符号**（`find_and_click` / `click_match` / `run_maa_phase` /
   `run_maaend_phase` / `execute_workflow` / `last_failure` / `_check_emulator_runtime`），
   只把 `execute_workflow` 改成「按 `control` 分派」。
3. **`orchestrator` 只依赖契约对象**：上游可注入，测试用 FakeUpstream 覆盖全部分支，
   不碰真实屏幕 / 进程 / 网络（约定见 `tests/conftest.py`）。
4. **日志判定三态**：判定不出来 → `UNKNOWN`，**禁止判成功**；`UNKNOWN` 降级到进程退出兜底。
5. **注入安全**：只写白名单键；快照 → 写 → 记账 `.injected.json` → 收尾还原；
   崩溃后下次启动补偿还原。

## 3. 模块落点

```
MaaAutoProject/
  upstream.py          契约：Issue / Outcome / Upstream / probe_exe
  run_state.py         状态枚举 + run_state.json 原子读写 + resume
  log_monitor.py       增量 tail、续行归并、规则表加载、MAA/ MaaEnd 判定器
  injector.py          MAA 配置注入（当前方案 / 白名单 / 快照 / 还原 / 补偿）
  upstream_maa.py      MAA 适配器
  upstream_maaend.py   MaaEnd 适配器
  orchestrator.py      一轮挂机的编排与重试
  selfcheck.py         只读自检（路径 / 日志 / 队列显影 / 冲突提示）
  resources/log_rules.json   内置规则表（可被远程同构文件覆盖）
  ui/setup_wizard.py   向导弹窗（自检结果 + 一键修复提示）
```

## 4. 回滚

任一阶段出问题：`git checkout -- MaaAutoProject`（本轮所有改动集中在新文件 + `automation.py`
分派 + `config_manager.DEFAULT_CONFIG` + `app_info.APP_VERSION`），旧路径 `control=click` 保底。
