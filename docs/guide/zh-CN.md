## 1. 这是什么

MaaAuto 是一个 Windows 桌面端的**调度外壳**：到点帮你拉起 [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights) 或 [MaaEnd](https://github.com/MaaEnd/MaaEnd)，用图像识别点掉「Link Start!」「开始任务」，等游戏退出，再把结果推送到微信或 Webhook。

它本身**不包含任何游戏逻辑**：不改游戏、不读内存、不模拟输入序列，只做三件事——**按日程启动、找图点击、进程守护**。

| 适合 | 不适合 |
| --- | --- |
| 每天固定时段挂机、希望全自动 | 需要多开、多账号批量托管 |
| 同时用 MAA 和 MaaEnd | 期望「零配置开箱即用」（仍需填两个程序路径） |
| 想在自己电脑上留痕（日志/推送） | 非 Windows 用户 |

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（x64） |
| 权限 | **安装**默认按用户安装，不需要管理员（选「为所有用户安装」才需要）；**程序运行**需要管理员，每次启动会弹一次 UAC |
| 磁盘 | 安装约 59 MB；运行另需日志空间（可设保留天数） |
| 显示 | 建议 1920×1080 及以上；125% / 150% 缩放下可用 |
| 外部程序 | MAA 与/或 MaaEnd，和一个安卓模拟器（如 MuMu） |
| 网络 | 检查更新、拉公告、推送需要；挂机本身可离线 |

> 只有勾选「完成后退出模拟器」的 MAA 才能被 MaaAuto 正确接管，见下一节。

## 3. 安装

### 3.1 安装包（推荐）

1. 打开 [Releases](https://github.com/mmccz/MaaAuto-Tool-works/releases/latest)；
2. 下载 `MaaAuto_Setup_v<版本>.exe`（约 59 MB）；
3. 双击运行，按向导走完：语言 → 安装目录 → 是否创建开始菜单/桌面快捷方式 → 安装；
4. 完成后可直接勾选「运行 MaaAuto」。

安装目录默认在 `%LOCALAPPDATA%\Programs\MaaAuto`，可改到任意位置（如 `D:\MaaAuto`）。

| 文件 | 用途 |
| --- | --- |
| `MaaAuto_Setup_v<版本>.exe` | 完整安装包（含全部运行文件） |
| `MaaAuto_Payload_v<版本>.zip` | 升级用的完整载荷（一般不用手动下载） |
| `MaaAuto_delta_v<旧>_to_<新>.zip` | 增量升级包，只有几百 KB，应用内升级时自动用 |
| `MaaAuto_Online_v<版本>.exe` | 约 2 MB 的在线引导器：下载安装包并校验后启动向导 |
| `SHA256SUMS.txt` | 全部资产的 SHA256 |

### 3.2 源码运行（开发者）

```powershell
git clone https://github.com/mmccz/MaaAuto-Tool-works.git
cd MaaAuto-Tool-works\MaaAutoProject
py -m pip install -r requirements.txt
py main.py
```

需要 Python 3.11 及以上（开发与 CI 用 3.15）。

### 3.3 安装后确认

- 桌面/开始菜单有 `MaaAuto` 图标；
- 「设置 → 应用」能搜到 MaaAuto，显示版本号（旧版本可能显示不准确，启动一次会自动修正）；
- 首次启动会弹出教程。

## 4. 首次启动：三条硬约束

教程里会强调下面几条，**这不是可选建议，是正确运行的前提**：

1. **MAA 里必须勾选「完成后退出模拟器」**。
   不勾的话，任务跑完模拟器还开着，MaaAuto 等不到「模拟器退出」信号，后续阶段和下一次启动都会失败。
2. **MaaEnd 任务列表的最后一步，必须加「关闭程序」或「关闭模拟器」**。
   顺序很重要：它必须是最后一条，否则 MaaEnd 会在任务没跑完时就把自己关掉。这条任务同时是 MaaAuto 判断「MaaEnd 跑完了」的信号。
3. **两个路径都要在设置里填对**：MAA 选 `MAA.exe`，MaaEnd 选 `MaaEnd.exe`。

做完第 1、2 步再去点「立即执行」，第一次就跑通的成功率最高。

## 5. 界面导览

主窗口分三页：

| 页面 | 内容 |
| --- | --- |
| **首页** | 运行状态、上次/下次运行、运行次数、日志面板（可清空）、「立即执行 / 停止」、公告入口、教程入口 |
| **设置** | 七组设置：路径、进程与超时、找图与点击、前台处理、定时与推送、外观、常规；顶部有跳转小标签 |
| **关于** | 版本与依赖版本、检查更新、打开配置目录/日志目录、导出日志、项目链接 |

托盘菜单（右键托盘图标）：显示、设置、停止、重启、退出。关闭窗口时是否留在托盘由设置里的「关闭到托盘」决定。

## 6. 设置详解

### 6.1 路径

| 项 | 说明 |
| --- | --- |
| MAA 路径 | 指向 `MAA.exe` |
| MaaEnd 路径 | 指向 `MaaEnd.exe`（可留空，只用 MAA） |
| Server 酱 SendKey | 微信推送用，[serverchan](https://sct.ftqq.com/) 申请；留空则不推送 |
| Webhook URL | 自定义 HTTP 推送地址；与 SendKey 可同时填 |

### 6.2 进程与超时

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 模拟器进程名 | `MuMuPlayer.exe` | 用于判断模拟器是否在跑 |
| PC 游戏进程名 | `Endfield.exe` | 用于判断游戏是否在跑 |
| 等待窗口超时 | 60 秒 | 启动程序后等窗口出现的时间 |
| 游戏启动超时 | 120 秒 | 从点开始到进入游戏的时间 |
| 游戏退出超时 | 7200 秒 | 等一局结束的最长时间 |
| 重试次数 / 间隔 | 3 次 / 30 秒 | 找图失败后的重试策略 |
| 模拟器最短运行 | 60 秒 | 模拟器启动即崩算失败，避免误报成功；0 = 关闭该判断 |

### 6.3 找图与点击

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 搜索范围 | 目标窗口 | 只搜目标窗口客户区；可选整屏 |
| 匹配阈值 | 0.80 | 越高越严格，越低越容易误匹配 |
| 缩放范围 / 步长 | 0.60–2.00 / 0.05 | 覆盖不同 DPI 与窗口尺寸 |
| 点击方式 | SendInput | 真实鼠标点击；PostMessage 为后台消息点击 |
| 点击前激活 / 还原鼠标 | 开 | 保证点在目标窗口上，且不打扰你的鼠标 |
| 点击校验 | 开 | 点完比较像素，判断点击是否真的生效 |
| 模板目录 | 空 = 内置 | 可指定自己的模板目录 |
| 截取模板 / 测试找图 | — | 从屏幕截一块存为模板；用当前模板试一次匹配 |

> 换 MAA 版本后如果突然「找不到 Link Start」，先用「测试找图」看分数，低于阈值就重截模板（MAA 改过按钮渲染）。

### 6.4 前台处理

| 模式 | 说明 |
| --- | --- |
| 不处理 | 任务结束后不动其他程序 |
| 关闭所有前台程序 | **风险高**：会关掉你能看到的前台窗口 |
| 只关黑名单 | 只关闭黑名单里的进程（逗号分隔，如 `WeChat.exe,QQ.exe`） |

「任务时最小化主窗口」建议保持开启：MaaAuto 自己的窗口容易盖住 MAA 的按钮。

### 6.5 定时与推送

| 项 | 说明 |
| --- | --- |
| 启用定时 | 打开后首页显示「下次运行」 |
| 时段 | 可加多个时间点，如 08:00、20:30；同一分钟只跑一次 |
| 工作日 | 只在这些天触发；全不选 = 每天 |
| 开机自启 | 登录后自动启动 MaaAuto（见第 10 节） |

### 6.6 外观

主题（跟随系统/浅色/深色）、强调色、背景图（不透明度/模糊/铺放方式）、界面缩放（1.0/1.25/1.5，按界面提示操作，通常需重启）、动画开关、界面语言（中文/English）。

### 6.7 常规

系统通知、关闭到托盘、退出时关闭相关进程、自动检查更新、自动下载更新、更新通道（stable / beta）、日志保留天数（默认 90 天，0 = 全部保留）。

## 7. 定时任务

1. 设置 → 定时与推送 → 打开「启用定时」；
2. 点「添加时段」，选时间（可加多个）；需要的话勾选工作日；
3. 回首页确认「下次运行」时间正确；
4. 到点自动开始，跑完推送结果并更新运行次数。

同一时刻不会重复执行：每个 `日期 + 时分` 只触发一次，手动执行过的分钟不会再被定时重复触发。

**错过时段也会补跑**：程序每 10 秒检查一次，如果当天该时段已过且还没执行过，会在启动后补跑一次。

**Q6 里的「界面缩放」改完如果界面没变**：按提示重启一次程序。

## 8. 运行、日志与推送

### 8.1 一次任务的流程

启动目标程序 → 等窗口 → 找图点击「Link Start!」等按钮 → 等游戏进程退出 → 前台处理（按设置）→ 推送结果 → 记录日志。

### 8.2 日志位置

```
<安装目录>\logs\<年>\<月>\<日>\run_<N>_<时分秒>\task.log
```

失败时同目录还会留一张失败现场截图（`find_fail_*.png`），方便看当时的画面。

首页的「清空」只清界面显示，不删磁盘文件；「关于 → 导出日志」可把日志打包带走。

### 8.3 推送

配好 SendKey 或 Webhook 后，每次任务结束会收到一条消息：开始时间、结束时间、状态（成功/失败）、日志摘要。推送失败不会影响任务本身。

## 9. 更新

- **手动**：关于页「检查更新」；
- **自动**：设置 → 常规 → 自动检查更新（可再加自动下载）；
- **增量**：新版本通常只有几百 KB 的差分包，应用内升级会自动选择增量或整包；
- 升级过程中主程序会被要求退出，升级器等它退出后替换文件并重启。

通道 `beta` 会包含预发布版本，追求稳定就用 `stable`。

## 10. 开机自启

| 安装形态 | 实现方式 | 检查方法 |
| --- | --- | --- |
| 安装包版本 | 登录计划任务 `MaaAuto`（最高权限运行，因此不会触发 UAC） | `schtasks /Query /TN MaaAuto /V /FO LIST` |
| 源码运行 | 注册表 `HKCU\...\CurrentVersion\Run` 下的 `MaaAuto` 值 | `reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v MaaAuto` |

用安装包版本时用计划任务，是因为 `MaaAuto.exe` 需要管理员权限，而注册表 Run 键无法启动提权程序。旧版本留下的 Run 键会在升级后自动迁移。

如果登录后没有自动出现，先看「关于 → 打开日志」，再按第 13 节排查。

## 11. 迁移、卸载与清理

- **换目录**：直接用安装包重装到新目录，配置和日志在旧目录的 `config\`、`logs\` 里，可手动拷过去。
- **卸载**：设置 → 应用 → MaaAuto → 卸载。**配置和日志默认保留**（不删用户数据），需要彻底清干净就手动删掉安装目录。
- **图标/「设置→应用」条目丢了**：运行安装器仓库里的 `repair_integration.py --dir <安装目录>` 修复。

## 12. 常见问题

**Q1 启动就提示需要管理员权限？**
正常，程序要操作其他窗口与进程。允许 UAC 即可。

**Q2 点了「立即执行」没有反应？**
先看路径是否填对、MAA 是否勾了「完成后退出模拟器」，再看首页日志有没有中文报错。

**Q3 找图失败 / 找不到 Link Start？**
用「测试找图」看置信度；低于阈值就重截模板；确认 MAA 界面语言与分辨率没变。

**Q4 任务跑完没有推送？**
检查 SendKey/Webhook、网络；推送失败不影响任务，日志里会有失败原因。

**Q5 为什么任务跑完模拟器没关？**
MAA 里没勾「完成后退出模拟器」，或者 MaaEnd 任务列表最后没有「关闭程序/关闭模拟器」。

**Q6 界面字号太小 / 太挤？**
设置 → 外观 → 界面缩放，改完重启。

**Q7 关闭窗口后程序不见了吗？**
看「关闭到托盘」是否开启；开着就在托盘里，右键托盘图标可显示。

**Q8 卸载后配置还在？**
设计如此（保留用户数据），手动删除安装目录即可。

**Q9 能多开吗？**
不支持，一个 MaaAuto 实例对应一个 MAA/一个 MaaEnd。

**Q10 升级会不会丢设置？**
不会，配置与日志在安装目录的 `config\`、`logs\` 中，覆盖安装与增量升级都保留。

## 13. 故障排查

| 症状 | 可能原因 | 处理 |
| --- | --- | --- |
| 提示「模板缺失」 | 模板文件被删/被改名 | 恢复内置模板或重截 |
| 提示「窗口不可见」 | 目标窗口最小化或在屏幕外 | 恢复窗口位置，关闭远程桌面 |
| 提示「模拟器启动失败」 | 模拟器秒退、ADB 连不上 | 手动启动一次模拟器确认可用 |
| 一直停在「等待窗口」 | 进程名填错 | 用「选择进程」重新选 |
| 点击没生效 | 窗口被遮挡、前台没抢到 | 开启点击校验、保持「任务时最小化主窗口」 |
| 登录后没自启 | 计划任务被组策略禁用 | 用安装包版本，或改为手动启动 |
| 深色主题下弹窗看不清 | 1.4.5 及更早版本的缺陷 | 已在开发分支修复，随下一个版本发布 |
| 升级失败 | 网络中断、安装器过旧 | 重新检查更新；提示「安装器过旧」时下载完整安装包 |

疑难的先跑「关于 → 导出日志」，把压缩包附在 issue 里。

## 14. 隐私、权限与安全

- 所有配置与日志都在**本机**安装目录，不上传；
- 联网只用于：检查更新（GitHub API）、拉取公告、你配置的推送；
- `MaaAuto.exe` 要求管理员权限，是因为要枚举/激活其他进程窗口、发送输入；
- 程序不读游戏内存、不注入、不修改游戏文件；
- Webhook/SendKey 属于敏感信息，存在本机 `config\config.json`，分享日志前先检查有没有泄漏。
